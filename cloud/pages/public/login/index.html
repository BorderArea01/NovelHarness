使用你设置的 PIN · 此设备保持登录 30 天

先验证部署口令，再设置你自己的 PIN。以后登录只需 PIN。

粘贴 owner-key.txt 中的整行口令。不是 PIN，也不是 DeepSeek Key。

口令在哪？

在部署数据目录的 owner-key.txt 中。请复制完整内容；它只用于恢复登录，不是模型 API Key。

暂时找不到时，先回到部署主机获取；不要填写模型 API Key。

身份已验证。设置一个以后登录用的 PIN。

4–12 位数字，公网建议至少 6 位。不要用生日或连续数字。

忘记 PIN？

使用部署主机 owner-key.txt 的完整口令，不是 DeepSeek Key。

PIN 保护你的书稿与模型额度。设置登录不需要重新配置 DeepSeek。
