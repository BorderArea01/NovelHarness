# Changelog

Versions follow Semantic Versioning.

## [5.0.0] - Unreleased

### Changed

- Retire the independent assistant workflow and generated `executionPrompt`, in addition to style/POV/cards/reference controls. Writing actions now send the author's request and a task handle; tools return structured scope/version/material data and the one selected, frozen task template. Tool definitions own commit/schema rules; existing task templates own creative guidance. No plugin prompt replacement or parallel purge editor remains. New books no longer create `AGENTS.md`/`START.md`; offline transactional migration backs up exact originals, consolidates custom requirements into the existing `setting.md`, and removes obsolete active configuration without changing original purge files. The prompt page contains only task templates. Source/isolated verification only: formal and LAN preview services are not updated by these changes.

- Default task templates no longer impose blanket word/punctuation bans, self-scoring, fixed outline-summary lengths or beat counts. Outline-first dependencies, original native question choices, mixed rewriting/continuation, automatic validated publication, author overrides, historical snapshots, version conflicts and history remain supported without a separate assistant-rule source.
- Added exact-match, transactional repair for untouched legacy book instructions and plugin defaults, with backups, plugin CAS/history, custom-text preservation and idempotence. The official-host injection provisioner backs up an untouched upstream factory prompt before installing the compact novel operator prompt; it does not remove the full plugin or host patches. Changes remain undeployed until the corresponding runtime/data update; active novels and conversations are not rewritten by source edits.

### Changed

- Schema 3 row-wise persistence is implemented in source and pending verification: unchanged chapters/history are no longer deleted and reinserted, chapter save times are preserved, explicit history order uses metadata-only updates, and unchanged project blobs and memory-to-card inputs avoid redundant writes. Transactional migration and row-write rollback tests are included; deployment is gated on these tests.
- The single-chapter PUT path is also pending verification: unchanged repeats retain revision and timestamp, stale revisions still conflict, and edited chapters use UPSERT without replacing their row identity.

- Server storage is authoritative. V4.4.3 is now a frozen migration source.
- The library and full AI workbench now share a cohesive, responsive dark writing-studio interface.
- Configured canvas AI actions execute in one click. Quality-first generation uses one additional model request for a causality-, agency-, scene- and voice-focused edit; the initial draft remains the recovery path.
- The editorial pass now rejects template-shaped repetition more explicitly while preserving genre-appropriate pacing, quiet chapter endings and the author's deliberate stylistic choices.
