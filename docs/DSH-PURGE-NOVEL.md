# dsh-purge 小说适配版（novel-1）

这是现有工作台内的可选扩展，**不是原版 dsh-purge 整包或破甲补丁的完整移植**。

来源：YuJunZhiXue/dsh-purge 1.1.82，固定提交 `0c933dc7d3252698f3f0f9756932dcc88355f532`。复用其提示词信封格式规范化逻辑，并保留原始版权、Apache-2.0 LICENSE 与 NOTICE（`cloud/pages/public/legal/dsh-purge/`）。默认提示词为本工作台的小说专用配置，不是原版混合攻防提示词；不保证改变 DeepSeek 服务端限制或提升实际写作质量。

## 使用与卸载

打开 **设置 → 通用设置 → dsh-purge · 小说适配版**：

- 修改附加提示词或启用勾选后，点击“保存插件设置”。提示词不能为空，最大 32 KiB。
- “立即停用”保留配置，但后续小说请求不再附加提示词。
- “提示词版本”可恢复以前的配置，恢复后保持停用，核对后再启用。
- “卸载适配版”需要在设置页内确认；移除当前配置，保留配置历史，不删除小说、聊天、PIN 或模型设置。重装后可以通过版本恢复取回旧提示词。

AI 正在运行或排队时，设置变更会被拒绝，不会中断任务；空闲后再操作。并发设置变更用内容版本校验，不能静默覆盖其他设备修改。

## 可逆性的准确含义

附加提示词只存在于**当次模型请求副本**，不进入原生 `system/message` 事件和聊天历史。停用、卸载后，同一对话后续请求也不再包含此前的插件提示词。原生提示词、工具列表、会话事件、请求统计、重试、停止、检查点、模型配置与权限不由插件替换。

停用不可能撤销已生成内容、已经消耗的模型额度或模型先前回答对故事的影响。需要撤销书稿修改时，使用书稿历史；需要全新聊天上下文时，使用“清空聊天／新对话”，同一本小说的书稿与资料仍保留。

适配代码仍随工作台发布包存在；界面卸载移除的是可选扩展的当前配置。需要移除代码时，可以在空闲、备份后回滚整个应用发布，**不要回滚数据库**。

重试、流式、停止和会话恢复继续使用原生机制，不增加另一套生成循环。

## 存储与恢复

使用当前唯一原生 SQLite/VFS 的 `/workspace/.novel-plugins/dsh-purge/config.json`；不另建数据库，不修改任何 `/workspace/novels/` 内容。设置快照保存在同目录 `history/`，写入、快照和卸载在同一原生事务内完成。配置损坏或含链接时不加载，设置页显示警告；不通过猜测配置启用功能。

安装前整库备份：`data/local-host/backups/before-ui-2026-10-28T17-26-37-785Z`。

应用回滚基线：`data/local-host/releases/2026-10-28T16-28-39-243Z-d6dfa234`。它保留手动删除、清空和恢复功能，未接入插件；回滚必须沿用当前本机数据库、原 PIN 和网络通道，先确认任务空闲并备份。
